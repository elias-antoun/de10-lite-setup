DE10-Lite tools setup

Get the Control Panel and System Builder working with Quartus Prime Lite 25.1std on Windows.

Download setup zip

Contains the bin32 folder and the DE10-Lite tools.

Before you start

  • Install Quartus Prime Lite 25.1std with MAX 10 device support.
  • Download the zip and extract it (right-click, then Extract All). Don't run anything from inside the zip.

The default for 25.1std is shown. If you installed it somewhere else, change it here and every path on this page updates.

Setup steps

  1. 1

    Copy bin32 into Quartus

    Copy the bin32 folder from the zip into your Quartus folder, next to the bin64 folder that's already there. You should end up with:

    The Control Panel is a 32-bit program, but Quartus only includes 64-bit tools. bin32 gives it the pieces it needs to talk to the board.

  2. 2

    Copy the DE10-Lite tools

    Copy the Tools folder from the zip into C:\DE10_Lite, so you have:

    C:\DE10_Lite\Tools
  3. 3

    Connect the board

    Plug the USB cable into the board's USB Blaster port and into your PC. The board is powered over USB, so it doesn't need a separate supply.

  4. 4

    Open the Control Panel

    Run:

    C:\DE10_Lite\Tools\DE10_Lite_ControlPanel\DE10_Lite_ControlPanel.exe

    When it connects, it loads its own design onto the FPGA and replaces whatever was there. That's expected; program your own design from Quartus again afterwards.

    To start a new Quartus project with the board's pins already assigned, run the System Builder. It works without the board connected.

    C:\DE10_Lite\Tools\DE10_Lite_SystemBuilder\DE10_Lite_SystemBuilder.exe

If something doesn't work

The Control Panel can't find the board
  1. Open Device Manager. If USB-Blaster has a yellow warning icon or shows up as an unknown device, right-click it, choose Update driver, then Browse my computer for drivers. Pick this folder and tick Include subfolders:
  2. Close the Quartus Programmer and anything else using the board, then open the Control Panel again.
  3. Check that bin32 is in the same folder as bin64 (step 1).
  4. Try a different USB port or cable.
I don't know where Quartus is installed

In the Start menu, right-click Quartus Prime, choose More, then Open file location. Right-click the shortcut that appears and choose Open file location again. You'll land in a folder ending in \quartus\bin64. Paste that path into the box at the top of this page; it removes the \quartus\bin64 part for you.
